# Ручная проверка сети доверия

Запуск: `scripts/nodes.sh 4 --fresh` — Alice, Bob, Carol, Dave (порты 7700, 7710, 7720, 7730).
Без `--fresh` узлы сохраняют ключи и поручительства — так проверяется п. 9.

Сеть доверия пересчитывается раз в минуту и через ~2 с после новых поручительств
или жалоб: если метка не сменилась сразу, подождите пару секунд.

## 1. Связь
- [x] У каждого узла на странице «Граф» видны остальные.
- [x] Сообщение Alice в «Глобальном» видят все.

## 2. Новички ограничены (фаза 3)
- [x] У всех в чате подсказка «За вас ещё никто не поручился…».
- [x] Alice быстро пишет 5 сообщений в «Глобальный» — у Bob дошли только 3, у сообщений метка «новичок».
- [ ] У Alice у 4-го и 5-го сообщения значок ⚠ («скорее всего, не дошло»), под полем ввода — обратный отсчёт до следующего сообщения.
- [x] Те же 5 сообщений в канале «Новички» — дошли все.

## 3. Поручительство (фаза 2)
- [x] Alice → профиль Bob → «Проверка контакта»: код совпадает с кодом в профиле Alice у Bob.
- [x] Alice «Поручиться: код совпал» → у Alice Bob «Проверен лично».
- [x] Carol так же ручается за Alice → у Carol Bob «Через знакомых: Alice».
- [x] Профиль Bob: «За вас поручились: 1»; подсказка новичка в чате у Bob пропала.
- [x] Bob пишет 5 сообщений подряд — у Alice и у Carol дошли все, без метки «новичок».

## 4. Личка и запросы (фаза 4)
- [ ] Dave открывает беседу с Alice: над перепиской подсказка «Собеседник вам ещё не писал… „Запросы“».
- [x] Dave пишет Alice: у Dave «Отправляется…» пару секунд (подбор марки), у Alice беседа в папке «Запросы».
- [x] Dave шлёт ещё 6 сообщений — у Alice в запросе не больше 5.
- [ ] У Dave 6-е и 7-е сообщения со значком ⚠.
- [x] Alice «Принять» — беседа во «Входящих», Alice может ответить.
- [x] Bob пишет Alice — сразу во «Входящие» (Bob проверен лично).

## 5. Наблюдения, сворачивание, встречающие (фазы 3, 6)
- [ ] До приветствия: профиль Dave у Carol — прогресс «ваш узел видит его N дн. из 7…» (его показывают только незнакомцам).
- [x] Bob: Настройки → «Сворачивать сообщения незнакомцев» — сообщения Dave свёрнуты, раскрываются щелчком.
- [x] Bob: «Я встречающий»; Dave пишет в «Новички» → у его сообщения «поприветствовать» → у Bob Dave «Освоившийся · вы поприветствовали».
- [ ] У Carol Dave теперь «Освоившийся · через Bob», а не «Через знакомых: Bob» — приветствие не поднимает выше освоившегося.

## 6. Жалобы (фаза 5)
- [x] Alice жалуется на Dave → у Alice Dave «Незнакомец · под жалобами», его сообщения свёрнуты с меткой «под жалобами».
- [x] У Carol (Alice для неё проверена лично) Dave тоже «под жалобами».
- [x] У Bob Dave не под жалобами: Bob ни за кого не ручался, Alice для него незнакомка.

## 7. Голосования (фаза 5)
- [x] У Dave кнопка «Создать» недоступна (за него никто не поручился).
- [x] Alice создаёт «Добавить канал», Bob голосует «За» → у Alice вес ≥ 1.5, доверенных 2, «идёт · принято».
- [x] Голос Dave у Alice не прибавляет веса.

## 8. Блокировка (фаза 4)
- [x] Alice → профиль Dave → «Заблокировать» — его сообщения в чате исчезли, личка от него не приходит.
- [x] «Разблокировать» — сообщения снова видны.

## 9. После перезапуска
- [x] Ctrl+C, затем `scripts/nodes.sh 4` (без `--fresh`) — метки доверия, «Входящие» и блокировки на месте.
